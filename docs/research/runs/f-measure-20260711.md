# F-MEASURE bounded rerun 2026-07-11

## Purpose

Define a portable, secret-safe F-MEASURE rerun without making product, capacity,
or plugin-traffic claims.

## Scope

Base: `7252f95314e746029f6ea04cd3deaf5fc4057051`. This harness creates fresh
evidence only when invoked. It discovers the worktree from its own `__file__`,
so the invocation CWD is irrelevant.

Each `repeat` creates one unique, owned directory directly below the system
temporary parent. It sanitizes every retained artifact and caps it at 8,192 UTF-8
bytes before indexing and hashing it. `repeat` rejects a pre-existing
`--raw-dir`; it never recursively deletes a configured root. The raw root,
artifacts, index, and checksum remain available after `repeat` for replay.

## Portable commands

Set `REPO` to an absolute Git worktree and derive the absolute script path.
These commands work from `/tmp`:

```sh
ROOT="$(git -C "$REPO" rev-parse --show-toplevel)"
SCRIPT="$ROOT/docs/research/runs/f-measure-20260711.py"
(cd /tmp && python3 "$SCRIPT" --self-test)
(cd /tmp && python3 "$SCRIPT" repeat --compose)
```

`repeat` prints `replay=... --raw-dir <owned-root>`. Run that exact command in a
fresh process before cleanup; it must report `F-MEASURE replay=PASS`. A `replay`
with neither `--raw-dir` nor `LKJMC_F_MEASURE_RAW_DIR` has no prior root and
reports `F-MEASURE replay=BLOCKED` with `index=missing`; that is distinct from
replaying the emitted root. Replay only rehashes the retained index and files,
so an altered artifact is `BLOCKED`.

After the needed replay, explicitly remove an emitted root only with:

```sh
python3 "$SCRIPT" cleanup --raw-dir <owned-root>
```

Before resolving a supplied path, cleanup rejects a final symlink, every
symlinked ancestor, and path traversal. It then accepts only a non-symlink,
owned, uniquely named direct child of the resolved system temporary parent.
Every other path is rejected before recursive deletion.

## Boundaries

The self-test runs `repeat`, extracts its emitted root, starts a fresh-process
`replay`, verifies the retained index and files, then verifies tamper detection
before explicit cleanup. It also covers out-of-worktree invocation, Unicode byte
truncation, arbitrary Bearer-token redaction, final and ancestor symlink refusal,
and existing unsafe-root refusal while their sentinels survive. A blocked Compose
lane is an external prerequisite failure, never database, menu, or plugin
evidence.
