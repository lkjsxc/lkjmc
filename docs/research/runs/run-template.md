# Run template

## Purpose

Use this template for one reproducible experiment execution.

## Template

```text
Run ID; experiment ID; candidate; base/result commits; worktree:
Host, limits, toolchain, runtime/database, data set, and seed:
Exact commands and exit statuses:
Baseline and variant metrics, invariants, faults, and recovery:
Sanitized artifact locations and deviations:
Secret-redaction, resource-cleanup, and git-status results:
External attempt, missing prerequisite, harness, and rerun command (if blocked):
```

## Boundary

State observations only. A run cannot claim adoption, rejection, or shipped
behavior; link a separate decision for interpretation.
