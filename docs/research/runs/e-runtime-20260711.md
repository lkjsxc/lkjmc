## Limits and cleanup

The local crash probe is a disposable Python coordinator, not a daemon restart.
The PostgreSQL lane proves real session connection loss and generation fencing,
but cannot recall an external effect already issued by a stale owner. Kubernetes
is planner-only: cluster effects, observations, and recovery are `BLOCKED`.
The next command above removes the raw root after reviewers finish replaying;
it is not part of the zero-survivor process proof.
