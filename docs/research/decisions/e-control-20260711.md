# E-CONTROL decision 2026-07-11

## Purpose

Interpret E-CONTROL research evidence without authorizing implementation or
shipment.

## Disposition

**BLOCKED; no COMBINE selection.** The prior `COMBINE` conclusion is withdrawn.
The repaired three-repeat Compose replay validates bounded local-component
invariants, but its durable journal cannot prove exactly-once external effects
across a post-launch crash.

## Rejected prior evidence

The observations in the superseded run did not use comparable async admission,
bounded mixed effect pressure, actor multi-key/rejection behavior, real
cancellation, concurrent duplicate effects, or child interruption cleanup. Its
runtime claim inferred behavior not exposed by the daemon. Its numbers,
connection counts, raw-log hashes, and selection therefore cannot support an
executor, journal, actor, or configuration decision.

## Current bounded findings

The repaired slice requires an explicit disposable flag and loopback or Compose
host, waits for database health, and uses actual candidate pool or mailbox
instances for controlled capacity-eight nonblocking rejection and drain. Mixed
checks its ingress and its effect pool separately, so it is local component
evidence rather than a complete overload comparison. The replay also validates
that `config.reload` rejects an invalid runtime memory setting rather than
claiming unobserved runtime reconstruction.

## Blocking limit

The journal fault durably creates intent and an effect claim, launches and
interrupts a child, and observes no durable completion. It leaves that attempt
unresolved and does not retry it: a parent crash in this interval cannot tell
whether an external effect occurred. Neither a journal nor this harness can
know whether retrying would duplicate the effect. No candidate can validly be
combined while that semantic, its external idempotency key, and a crash-safe
adapter are absent.

## Reconsideration

Have an independent reviewer inspect the sanitized Compose output and
invariants. Then define an effect boundary with a real idempotency key or mark
exactly-once out of scope before comparing product adapters. No daemon
implementation task or state-document row is created by this decision.
