# E-SYNTHESIS per-ID disposition inventory

## Purpose

Dispose of all 150 imported idea IDs without turning an experiment into product
behavior. The catalog name is the hypothesis where no narrower hypothesis exists.
Every row has evidence or an exact attempt; the 34 former `no ` rows cite the
source-anchored [raw manifest](../runs/e-synthesis-20260712-raw-manifest.json).

## Disposition key

`S-C` selected contract input: real handler schemas, consumer inventory, stale
output gate, then `S-Q` and `S-S`; no adapter restoration. `S-S` selected
security research input: owner threat model, off-reactor work, and fail-closed
cache/listener/repair/database uncertainty proof. `S-Q` selected verification
input only; pair it with a real later boundary. `S-U` selected PostgreSQL
cutover rehearsal only; pair it with a PostgreSQL-only proposal. `S-L` retains
only the existing local menu boundary. `B-E` needs a real idempotency key,
crash-safe adapter, durable intent/effect/observation correlation. `B-I` needs
trusted identity/session attestation, a nonblocking real Java adapter, and a
client-observed outcome. `B-O` needs an independent attested observer event,
durable correlation, daemon-path fault, and 30 repeats. `B-X` needs the exact
recorded external prerequisite and rerun. `R-P` conflicts with a measured or
fixed boundary; reconsider only with a separate proposal closing its named gap.
`N` has an evidence attempt but still needs an owner-scoped hypothesis and
relevant bounded real run. None authorizes adoption or treats a blocked guard as
capability evidence.
