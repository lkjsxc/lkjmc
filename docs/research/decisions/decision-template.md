# Decision template

## Purpose

Use this template to interpret reviewed experiment evidence for a candidate.

## Template

```text
ID, disposition (adopt/reject/combine/external proof pending):
Baseline, variant, combination, and independent-review evidence:
Invariant, security, recovery, performance, and cost comparison:
Reason and positive/negative combination findings:
Reconsideration conditions and retained branch/commit:
Adoption or cleanup task; owner/state docs affected:
External prerequisite and exact rerun command (if pending):
```

## Boundary

Adoption is not implementation. It needs a separate task, real adapter work,
owner-contract update, and state proof. Rejection remains discoverable.
