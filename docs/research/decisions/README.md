# Research decisions

## Purpose

This index preserves evidence-backed adoption, rejection, combination, and
external-proof-pending decisions for research candidates.

## Table of contents

- [Decision template](decision-template.md)

## Decision boundary

A decision must cite baseline and variant runs, invariant results, costs, and
reconsideration conditions. Rejection keeps its evidence and branch reference;
it does not leave a fake runtime registration. Adoption requires a separate
implementation task and owner/state documentation.
