## Evidence and disposition

The catalog is source evidence for the 150 imported IDs. E-CONTRACT, E-CONTROL,
E-DATA, E-HC-AUTOMATION, E-HC-CONTROL, E-HC-PLATFORM, E-HC-SURFACE, E-JVM,
E-OBS, E-OPS, E-PRODUCT, E-QUALITY, E-RUNTIME, and E-SECURITY have bounded
research records in the sibling indexes. [E-SYNTHESIS](../decisions/e-synthesis-dispositions-20260712.md)
records every ID's evidence and non-product disposition. A later product change
still needs a hypothesis, reproducible run, owner contract, and implementation
task; the synthesis does not adopt behavior.

## Decision boundary

Only an owner contract and state evidence can describe shipped behavior. A
research ID may become an implementation task only after its decision cites a
real run and preserves reconsideration conditions.
