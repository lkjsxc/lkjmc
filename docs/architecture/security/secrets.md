# Secrets

## Purpose

This document defines secret handling rules.

## Rules

- PostgreSQL credentials are secrets.
- Generated secrets are stored in root-readable files with `0600` permissions.
- Secrets are not printed after creation.
- Plugin HTTP uses a shared local token unless a stronger local mechanism is
  implemented.
- Daemon HTTP listens on loopback by default.

## Current status

`scripts/install.sh` generates the PostgreSQL password file at
`/etc/lkjmc/database.secret` or the configured `LKJMC_CONFIG_ROOT` equivalent
with `0600` permissions and never prints the generated value. The installer also
writes the daemon environment file with `0600` permissions. Daemon HTTP tokens
are still provided through environment/configuration rather than generated by a
dedicated token command.
