# Minecraft commands

## Purpose

This document defines the target in-game command surface.

## Velocity commands

- `/lkjmc`
- `/lkjmc status`
- `/lkjmc server list`
- `/lkjmc server start <server>`
- `/lkjmc server stop <server>`
- `/lkjmc server restart <server>`
- `/lkjmc server create <server> <template>`
- `/lkjmc server delete <server>`
- `/lkjmc send <player> <server>`
- `/lkjmc reload`
- `/hub`

## Paper and Folia commands

`/menu`, `/lang`, homes, warps, teleport, points, shop, party, and achievements
are target commands. None are implemented yet.
